# Shotgrid REST API Client

[![Python](https://img.shields.io/badge/python-3.9%20%7C%203.10%20%7C%203.11-blue)](https://www.python.org/downloads/)


A modern async Python client for the Autodesk Shotgrid (Flow Production Tracking) REST API using [`httpx`](https://www.python-httpx.org/) and [`authlib`](https://authlib.org/).

## Features

- Async/await support using httpx
- OAuth2 authentication with Authlib
- Type hints and Pydantic models
- Simple high-level API interface

Super early expirmental developement.
